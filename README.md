The aqm project is an experimental, proof-of-concept data application to merge data pulled from news sources, EPA air quality data, and ClimateTRACE emissions data into an explorable map.

## Data Sources
* [EPA - Air Quality System](https://aqs.epa.gov/aqsweb/documents/data_api.html)
* [ClimateTRACE](https://api.climatetrace.org/v7/docs/index.html#tag/emissions-sources)
* [NewsAPI](https://newsapi.org/)
